# Inject｜前端页面设计规范

## 1. 视觉方向

整体风格：高端、理性、克制、清晰。采用暖白背景、深墨蓝正文、低饱和酒红强调、少量古铜辅助。避免霓虹色、蓝紫科技渐变、大面积灰色文字和厚重阴影

字体优先：

`Source Han Sans SC / 思源黑体 CN / Noto Sans CJK SC / Noto Sans SC`

## 2. 页面结构

1. 顶部状态栏
2. Hero：所有子网，追踪每个区块的真实排放
3. 全部子网监控
4. 子网与时间查询
5. 五个 KPI
6. 区块注入趋势
7. 全部区块明细

## 3. 全部子网监控

整页宽度。字段：

- 子网
- 链上实际注入
- 理论计算
- 偏差
- Chain Buys
- Total Emission
- 状态

子网列左对齐，其余列水平/垂直居中，左右视觉留白一致。搜索框位于右上角，输入 SN / 名称即时过滤

## 4. 查询区域

位于全部子网监控下方，一行展示：

- 监测子网查询
- 24 小时 / 7 天 / 30 天 / 自定义
- 开始时间
- 结束时间
- 查询区块

快速范围标签严禁换行，查询按钮始终一行

## 5. KPI

- 链上实际总注入
- 理论计算总注入
- 累计偏差
- 区块数量
- 平均每区块注入

实际总注入为主卡片，使用深墨蓝底 + 白字 + 极细古铜辅助线

## 6. 区块趋势

主线：低饱和酒红

理论线：古铜

支持每区块与按小时聚合。原始区块数据必须完整保存，图表可按显示性能抽样

## 7. 全部区块明细

字段：序号、区块高度、区块时间、链上实际注入、理论计算注入、单区块偏差、累计偏差、累计实际注入

所有字段居中。右侧搜索框“搜索区块高度 / 时间”，输入后即时过滤，无跳转按钮

点击任意表头排序，再次点击切换升降序，并显示 ↑ / ↓

24 小时约 7200 行、30 天约 21.6 万行均采用虚拟滚动，不使用分页 UI

## 8. 字号

- Hero：约 54 px
- 模块标题：18 px
- 表头：13 px / 700
- 表格正文：15 px
- KPI：33–40 px
- 搜索 / 筛选：13–14 px

Windows 浏览器下优先保证清晰度，不使用过细字重

## 9. 状态与异常

RPC 正常：低饱和深绿

RPC 异常：低饱和深红，并保留最后同步区块

理论公式未启用时：理论值与偏差显示 `—`，不得显示 0 或模拟值

无数据时显示“该时间范围暂无区块数据”，避免将空数据误解为 0 排放
